# superstore-sales-dashboard
This project is an interactive dashboard created using Tableau to analyze Superstore sales data and generate business insights through data visualization.

The dashboard helps in understanding:

Sales performance
Profit analysis
Order trends
Quantity distribution
Region-wise performance
Segment-wise sales analysis
Monthly sales trends

Tools Used:

Tableau

Project Features:

Interactive dashboard design
KPI overview
Sales and profit tracking
Regional comparison analysis
Customer segment insights
Monthly trend visualization

Dataset:
The dataset contains Superstore order details including sales, profit, quantity, region, and customer segments.

Project Outcome:
This dashboard provides clear insights into business performance and supports data-driven decision making.
